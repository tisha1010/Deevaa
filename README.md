# 🌸 Deevaa – Luxury Beauty & Cosmetics Website

Deevaa is a modern luxury beauty and cosmetics website designed and developed using **WordPress**, **WooCommerce**, **Elementor**, and the **Blocksy Theme**.  
The project focuses on delivering a premium shopping experience with elegant visuals, modern layouts, and responsive design.

---

# ✨ Features

- Elegant luxury-inspired UI/UX
- Fully responsive design
- WooCommerce product integration
- Modern landing page design
- Product showcase & category sections
- Best sellers collection
- Customer testimonials section
- Newsletter subscription form
- Custom shop page design
- Premium visual aesthetics
- Clean typography and spacing

---

# 🚀 Setup Instructions

## 1️⃣ Clone Repository

```bash
git clone https://github.com/tisha1010/Deevaa.git
```

---

## 2️⃣ Move Theme Files

Copy the following folders into:

```bash
wp-content/themes/
```

- blocksy
- blocksy-child

---

## 3️⃣ Activate Theme

Go to:

```bash
WordPress Dashboard → Appearance → Themes
```

Activate:
- Blocksy
- Blocksy Child

---

## 4️⃣ Install Required Plugins

Install and activate:

- WooCommerce
- Elementor
- Blocksy Companion
- Elementor Header & Footer Builder
